# 💜 เว็บไซต์เซอร์ไพรส์ครบรอบ — คู่มือฉบับละเอียด

## โครงสร้างไฟล์
```
anniversary-site/
├── index.html              ← หน้าเว็บหลัก (5 หน้า รวมอยู่ในไฟล์นี้)
├── admin.html               ← หน้าจัดการรูปภาพอัลบั้ม (ใช้เฉพาะตัวคุณ)
├── css/style.css            ← สีและดีไซน์ทั้งหมด (ธีมม่วงพาสเทล)
├── js/translations.js       ← ข้อความ 3 ภาษา (ลาว/ไทย/อังกฤษ)
├── js/content-data.js       ← ข้อความหน้าจดหมาย + หน้าปิดท้าย (แก้เอง)
├── js/album-data.js         ← รายการรูปอัลบั้ม (ค่าเริ่มต้น)
├── js/audio.js              ← เสียงเอฟเฟกต์หัวใจ + ฟังก์ชันหัวใจลอย
├── js/app.js                ← ตรรกะหลักทั้งหมด (ไม่ต้องแก้ ยกเว้นวันเริ่มคบกัน)
├── images/                  ← รูปพื้นหลัง/ปุ่มที่คุณส่งมาให้ (ตั้งชื่อใหม่ให้จำง่าย)
│   ├── bg-couple.jpg         (หน้า Welcome / เค้ก / ปิดท้าย)
│   ├── popup-monthiversary.png (popup หน้าแรก)
│   ├── btn-cake.png          (ปุ่มเค้กหน้า 2)
│   ├── bg-letter.png         (พื้นหลังหน้าจดหมาย)
│   ├── bg-album.png          (พื้นหลังหน้าอัลบั้ม)
│   └── album/                (ใส่รูปอัลบั้มเพิ่มเติมได้ที่นี่ ถ้าไม่ใช้ admin.html)
└── music/
    └── song.mp3              ← ⚠️ คุณต้องนำไฟล์เพลงมาวางเอง ตั้งชื่อว่า song.mp3
```

## ✅ สิ่งที่คุณต้องทำเอง (จุดที่ต้องแก้ไข)

### 1. ใส่ไฟล์เพลง
นำไฟล์เพลงของคุณไปวางในโฟลเดอร์ `music/` และตั้งชื่อไฟล์ว่า **`song.mp3`**
(ถ้าอยากใช้ชื่ออื่น ให้เปิดไฟล์ `index.html` แล้วแก้บรรทัด
`<audio id="bgm" src="music/song.mp3">` ให้ตรงกับชื่อไฟล์ของคุณ)

### 2. เขียนข้อความจดหมาย + ข้อความปิดท้าย
เปิดไฟล์ **`js/content-data.js`** แล้วแก้ข้อความในเครื่องหมาย `` ` `` (backtick) ได้เลย:
- `letterText` → ข้อความหน้าจดหมาย (หน้า 3)
- `endText` → ข้อความหน้าปิดท้าย (หน้า 5)
กด Enter ขึ้นบรรทัดใหม่ในนั้นได้ตามสบาย

### 3. แก้/เพิ่มคำแปล 3 ภาษา
เปิดไฟล์ **`js/translations.js`** — แบ่งเป็น 3 ส่วนชัดเจน (`la`, `th`, `en`)
แก้ข้อความในเครื่องหมาย `"..."` ของแต่ละภาษาได้เลย ห้ามลบชื่อ key ด้านซ้าย

### 4. เพิ่ม/แก้รูปภาพในอัลบั้ม (แนะนำ — ไม่ต้องแตะโค้ด)
เปิดไฟล์ **`admin.html`** ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย หรือเปิดผ่านเว็บถ้าอัปโหลดแล้ว)
1. เลือกรูปภาพ → ใส่ชื่อรูป → ใส่รายละเอียด/ความรู้สึก → กด "เพิ่มรูปนี้เข้าอัลบั้ม"
2. ทำซ้ำได้ไม่จำกัดจำนวนรูป
3. เมื่อเพิ่มครบแล้ว **กด "สร้าง & คัดลอกโค้ด"** ที่ด้านล่างสุด
4. เปิดไฟล์ `js/album-data.js` แล้ว**ลบเนื้อหาเดิมทั้งหมด วางโค้ดที่คัดลอกมาแทน**
5. บันทึกไฟล์

> ⚠️ **สำคัญมาก**: รูปที่เพิ่มผ่าน `admin.html` จะถูกเก็บไว้ใน "เบราว์เซอร์ของคุณเครื่องนั้น" เท่านั้น
> ถ้าไม่ทำขั้นตอนที่ 3-4 (คัดลอกโค้ดไปวางในไฟล์จริง) **แฟนของคุณจะไม่เห็นรูปที่คุณเพิ่ม** เพราะรูปยังไม่ได้ติดไปกับตัวเว็บที่อัปโหลด

### 5. เช็ควันเริ่มคบกัน (ตั้งไว้ให้แล้ว)
ในไฟล์ `js/app.js` บรรทัดบนสุด:
```js
const START_DATE = new Date(2026, 6, 20, 0, 0, 0);
```
ตั้งไว้เป็น **20 กรกฎาคม 2026 เวลา 00:00 น.** ตามที่แจ้งไว้แล้ว (เลขเดือนในโค้ดเริ่มนับจาก 0 ดังนั้น `6` = เดือนกรกฎาคม ถูกต้องแล้ว ไม่ต้องแก้อะไร เว้นแต่วันที่เปลี่ยน)

## ⚠️ ข้อจำกัดที่ควรรู้ (สำคัญ)

1. **เพลงอัตโนมัติ**: เบราว์เซอร์ส่วนใหญ่ (โดยเฉพาะ iPhone/Safari) จะ**บล็อกเสียงอัตโนมัติ**จนกว่าจะมีการแตะจอครั้งแรก โค้ดนี้ตั้งไว้ให้เพลงพยายามเล่นทันที และถ้าเล่นไม่ได้จะเริ่มเล่นทันทีที่แตะจอครั้งแรกแทน (แทบจะพร้อมกับตอนเปิดเว็บอยู่ดี เพราะต้องแตะเพื่อดูหัวใจ/ไปหน้าถัดไปอยู่แล้ว)
2. **ล็อกแนวตั้ง**: เว็บเบราว์เซอร์ไม่สามารถ "บังคับล็อก" การหมุนจอได้จริงแบบแอป จึงทำเป็น**ข้อความเตือนเต็มจอ**ให้หมุนกลับเป็นแนวตั้งแทน หากแฟนคุณหมุนจอเป็นแนวนอน
3. **รูปในอัลบั้มจาก admin.html**: ตามที่อธิบายในข้อ 4 ด้านบน ต้อง Export โค้ดมาวางในไฟล์จริงก่อนส่งเว็บให้แฟน ไม่งั้นแฟนจะไม่เห็นรูป
4. **ขนาดไฟล์**: ถ้าอัปโหลดรูปความละเอียดสูงมากๆ เข้าอัลบั้มเยอะๆ เว็บอาจโหลดช้าลง แนะนำใช้รูปที่ไม่ใหญ่เกินไป (ไม่เกิน ~2MB ต่อรูป)
